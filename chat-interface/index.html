OpenClaw Agent Hub

This LAN-only launcher opens the built-in OpenClaw control chat with the correct gateway token and jumps straight into the main session for the agent you choose.

Target gateway: wss://192.168.2.142:5173/openclaw

Rem

Main OpenClaw agent session.

Nyx

Coding and implementation agent.

Kai

Analysis and structured-output agent.

Moh

General-purpose Anthropic-backed OpenClaw agent.

The OpenClaw control UI itself provides the in-chat agent switcher. Once it opens, you can change agents from the chat header and move between sessions without coming back here.

This launcher passes the gateway token and session directly into the proxied OpenClaw UI, then OpenClaw strips them from the URL after loading.
